# Profile Website

Starter portfolio berbasis Next.js, TypeScript, dan Tailwind CSS.

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000).

## Perintah tersedia

- `npm run dev` — menjalankan development server
- `npm run lint` — memeriksa lint
- `npm run build` — membuat production build
- `npm run start` — menjalankan production build

Halaman utama ada di [`src/app/page.tsx`](./src/app/page.tsx), sedangkan styling global ada di [`src/app/globals.css`](./src/app/globals.css).
